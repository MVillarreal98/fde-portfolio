# Changelog

All notable changes to the Document Layout Automator are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.1.0] - 2026-10-22
### Fixed
- Output lines were not actually fixed-width. A value longer than its field
  was written in full and shifted every later field: `PSKG` gave 32-character
  lines, and the Carrier ASN date always gave 29 instead of 27. A value that
  does not fit now rejects the row with `excede el ancho fijo de N caracteres`.
  It is never truncated.
- Guía Depósito: `moneda` had width 2 but received `MXN`, so lines were 31
  characters against a declared 30. The field is now 3 wide and the profile
  totals 31.
- Guía Depósito: `record_type` is validated (must be `PKG`, default `PKG`).
- Carrier ASN: `ship_date` must be a real calendar date in `yyyy-MM-dd` and is
  written as `yyyyMMdd` in its 8-character field. Before this fix, the profile
  could never produce a valid line. `weight_kg` no longer combines
  `Required` with a dead default.
- `RejectedRows` counted errors instead of rows. A row with two problems now
  counts as one rejected row and still lists both problems.
- Amounts and weights require exactly two decimals, so `602` and `602.00` can
  no longer produce two different representations of the same value.
- Values with non-ASCII characters are rejected. Before, the ASCII output
  silently turned them into `?`.
- The operator sees a plain-language hint instead of the raw regex. Patterns
  are anchored once and use `[0-9]` instead of Unicode `\d`.
- A locked or unreadable file shows a message instead of crashing the app.
- `sample_output/` had been written by hand and did not match the code. It
  reported 5 rejected rows *and* a generated file, which fail-closed never
  produces, and it contained a local absolute path and a file name the code
  does not generate. It is now regenerated by `tools/LayoutCli`, with one
  successful run and one rejected run (no file). Tests fail if it drifts.
- The screenshots showed a misaligned row next to "Layout íntegro". They were
  recaptured from the fixed build, without local paths.
- Tests that pinned the bugs (a 31-character line under a 30-character spec,
  and a 10-character date in an 8-character field) were rewritten.

### Added
- `LayoutProfile.OutputSlug`, a stable ASCII file-name slug (`deposit_guide`,
  `carrier_asn`), and `LayoutProfile.RecordWidth`.
- `services/LayoutRunner.cs`: the read → transform → fail-closed write, shared
  by the WPF window and the new console runner `tools/LayoutCli`.
- `tools/LayoutCli`, a console runner with exit codes 0 (file generated),
  1 (rows rejected, nothing written) and 2 (usage or file error).
- Tests: every profile's lines measure exactly the sum of the field widths, plus
  tests for overflow, dates, record type, distinct row counting, ASCII,
  fail-closed and the committed `sample_output/`.
- `capture.ps1 -Name <file>.png`.
- README: field-by-field spec for each profile, and a Limitations section.

### Removed
- Dead `ColumnMapping.Apply`, the unused `skipHeader` parameter, and the
  nullable `FixedWidth` (every column now declares its width).
- README claims that were not true: a configurable delimiter, amount formatting,
  and a rollout "without breaking partner ingestion". Neither the tool nor its
  data has been used in production. The specs and data are synthetic.

## [1.0.0] - 2026-10-22
### Added
- WPF single-screen operator app: profile picker, source preview,
  per-line diagnostics, run summary, artifact path in status bar
- Declarative layout engine (`LayoutTransformer`): per-column rules with
  requiredness, fixed widths, zero/left/right padding, regex validation
  and defaults; header-aware CSV reader honoring quoted cells
- Two built-in profiles: Guía Depósito (fixed-width deposit guide)
  and Carrier ASN (per-store packing totals)
- Fail-closed run: no artifact is generated while any row is rejected
- Five xunit tests covering padding, defaults, required/regex/overflow
- Packaging: solution file, .editorconfig; dev tooling (Coverlet coverage)
