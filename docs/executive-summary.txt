------

portfolio follows one arc:

    Here was the daily problem -> Here is the tool I built -> Here is what it saved.

RESULTS
-------
1) RECONCILIATION ENGINE (Python, Pandas, unit tests)
   Problem: daily reconciliation between operational records and
   billing/settlement data was manual (+240 invoices/day audited) and
   missed systemic anomalies.
   Delivered: modular pipeline - ingestion with schema validation, cent-level
   cleaning, cross-matching by transaction reference, four deterministic
   anomaly rules (duplicate settlements, amount mismatches, orphaned
   transactions, duplicate same-day charges), executive Markdown report +
   per-rule CSV exports.
   Impact: replaced hours of manual cross-checking with a repeatable
   5-minute run; anomalies surface daily instead of at month-end. Sample
   run on shipped demo data: 24 transactions reconciled, 4 rules fired,
   net flagged difference $2,363.00 MXN.

2) LLM SUPPORT-CLAIM TRIAGE AGENT (Python, Ollama REST, web UI, on-premise)
   Problem: support teams triage high volumes of unstructured claims with
   inconsistent classifications and no audit trail.
   Delivered: web application integrating a local LLM - code-owned system
   prompt with typed context injection, protocol-level JSON output contract
   with fail-closed schema validation, deterministic rules layer above the
   model (refund autocap, low-confidence escalation, unauthorized-charge
   severity override), and an auditable keyword fallback classifier that
   keeps the desk running when inference is down.
   Impact: production-shaped agent flow (classify claim, summarize history,
   propose resolution) that runs fully on-premise so payment data never
   leaves the network; every decision shows its source (llm/fallback) for
   auditability.

3) DOCUMENT LAYOUT AUTOMATOR (C# / .NET 8 / WPF, Windows desktop MVP)
   Problem: operators re-formatted files by hand for downstream ERP and
   carrier systems - repetitive, zero-tolerance, error-prone.
   Delivered: single-screen desktop app with a declarative layout engine
   (fixed widths, zero/left/right padding, regex validation, defaults),
   header-aware CSV reader, per-row diagnostics with line numbers and
   plain-language reasons, and a fail-closed rule: no output file is
   generated while any row is rejected.
   Impact: hand-edited layouts disappeared from the daily routine;
   operators complete in minutes what required careful manual sessions,
   with same-input/same-output determinism guaranteed by 5 unit tests.
